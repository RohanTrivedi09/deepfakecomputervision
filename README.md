# Deepfake / Face-Swap Detection Platform

Binary real-vs-fake face classifier (ResNet18, transfer learning) with Grad-CAM
explainability, served through a Streamlit demo (file upload + webcam snapshot).
Sem 7 computer vision course project — see `deepfake-detection-plan.md` for the
full scope, rationale, and locked v1 decisions.

Trained on the [140k Real and Fake Faces](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces)
dataset (70k real / 70k StyleGAN-fake), using a stratified ~24k-image subset.

## How this repo is organized

Training is compute-heavy (24k images, ResNet18 fine-tuning) and this repo is
developed on a machine without a dedicated GPU, so **training runs on Google
Colab**, not locally:

- `src/` holds the real pipeline code (data download, preprocessing, training,
  evaluation, Grad-CAM, inference) as plain, reusable `.py` scripts/modules —
  not notebook cells.
- `notebooks/colab_train.ipynb` is a thin runner: it clones this repo on Colab,
  installs the couple of extra deps Colab doesn't already have, authenticates
  Kaggle, and calls the `src/` scripts in order on Colab's free GPU.
- `app/streamlit_app.py` and everything else runs **locally** — it only needs
  the trained checkpoint (`models/checkpoints/best_model.pth`), not the dataset
  or a GPU.

## Running the training pipeline (Colab)

1. Open `notebooks/colab_train.ipynb` in Google Colab (upload it, or open
   directly from the GitHub repo via Colab's "File → Open notebook → GitHub" tab).
2. Runtime → Change runtime type → GPU (T4).
3. One-time: create a Kaggle API token at kaggle.com/settings → API, then add
   `KAGGLE_USERNAME` and `KAGGLE_KEY` as Colab Secrets (key icon in the left
   sidebar), with notebook access enabled.
4. Run all cells. This downloads the dataset, builds the stratified subset,
   trains, evaluates, and generates Grad-CAM samples.
5. Bring the results back to your local clone — either have Colab push them
   back to GitHub directly (needs a `GITHUB_TOKEN` Colab secret, see the
   commented-out cell), or download the zipped `models/checkpoints/` and
   `reports/` and unzip them into the same paths locally.

## Running the demo (local)

```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt

streamlit run app/streamlit_app.py
```

Requires `models/checkpoints/best_model.pth` to exist (brought back from Colab
per above). Open the local URL Streamlit prints, then use either the "Upload
image" or "Webcam snapshot" tab.

## Repository structure

```text
data/               # gitignored — populated by src/preprocessing scripts (Colab)
notebooks/
  colab_train.ipynb # thin Colab runner for the full training pipeline
src/
  common/           # shared path constants
  preprocessing/    # Kaggle download, stratified subsampling, dataset/dataloaders
  training/         # model definition (ResNet18) + training loop
  evaluation/       # metrics/confusion matrix + Grad-CAM generation
  inference/        # shared predict() used by the Streamlit app
models/checkpoints/ # best_model.pth (committed once trained — small enough for git)
app/
  streamlit_app.py  # demo UI: upload / webcam -> prediction + Grad-CAM
reports/
  metrics.json, figures/  # generated by src/evaluation
  project_report.md       # course write-up (approach, results, limitations)
```

## Known limitations (v1)

- Trained on one GAN family (StyleGAN) — may not generalize to deepfakes from
  other generators (a known hard research problem, not attempted here).
- Static images only, no video/temporal deepfake detection.
- Binary real-vs-fake only, no sub-typing of which method generated a fake.

See `reports/project_report.md` for the full write-up once trained.
